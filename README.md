# projeto-integrado-mobile-secure-growth
Secure Growth: app mobile de controle financeiro pessoal que ajuda o usuário a registrar receitas e despesas, organizar gastos por categoria e acompanhar a saúde financeira em um dashboard. Projeto integrador do curso de Engenharia de Software (UNICEPLAC), feito com React Native, Expo, TypeScript e Supabase.
